## Code Changes

### Earlier same-day console wave

`components.ts` added private ALL-view cursor state (`allViewCursor`, `allViewRowMap`) and row-map driven navigation; job actions now select repo synchronously before opening views. `types.ts`/`runtime.ts` added optional `RuntimeClient.stopJob?()` and `LocalRuntimeClient` support via `stopJobControl`. `theme.ts` added `paintBar()` and black-on-white keybar rendering, while the red stats bar was reverted. `config-source.ts` now reads package defaults using `resolveCanonicalAssetDir('specialists')` so inherited config values render correctly regardless of cwd. ### xtrm-tools / core dependency capability (`xtrm-dev/core#315`)

Added `.xtrm/skills/default/updating-dependencies/` with the v0 operational skill, upgrade dossier, PR comment, research matrix, post-deploy watch templates, and JSON schemas. Added `scripts/dep-inspect.mjs` as the deterministic case builder: semver/update-kind classification, manifest scope inference, cooldown evaluation, OSV lookup, CVSS v3 vector scoring, SECURITY_FORCED inference, EPSS bucket approximation, and preliminary verdict taxonomy. Added `scripts/dep-inspect.test.mjs` (final 11/11). Added `.github/actions/dep-review/` wrapper that materializes a case, renders a PR comment, and applies verdict labels. Updated core `.github/workflows/osv-scanner.yml` so PR scans are advisory while push/schedule scans remain hard gates. Regenerated `.xtrm/registry.json` and updated `CHANGELOG.md`.

### specialists dependency CI adoption (`xtrm-dev/specialists#154`)

Updated `.github/workflows/osv-scanner.yml` with separate PR/protected branch behavior: PR job captures JSON/status, classifies through `scripts/osv-security-forced-classifier.cjs`, blocks only when SECURITY_FORCED count is non-zero, and preserves required status context `OSV scan`; protected branch/schedule job remains a hard gate. Added Node-old-runner-compatible CommonJS classifier with CVSS v3 base-score computation and KEV/active-exploit handling. Updated `.github/workflows/package-payload.yml` to split install/build/pack/assert surfaces. Added `scripts/materialize-dependency-verdict.mjs` plus tests to emit dry-run advisor/followup/gate artifacts from dependency verdicts. Added `docs/devops/dependency-verdict-materialization.md` and OpenWolf bookkeeping updates.

### xtrm policy doc (`xtrm-dev/xtrm#8`)

Added `docs/devops/dependency-bump-policy.md` defining the policy: PR OSV advisory by default, SECURITY_FORCED block, push/schedule hard gates, 7-day cooldown, evidence-first verdict taxonomy, and repo transition guidance. Codex feedback was folded in before merge: PR workflows must preserve OSV JSON/status before classification and the default config filename is `osv-scanner.toml` unless `--config` is supplied.
